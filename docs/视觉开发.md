## 3.CRTC2026 视觉开发日志

**日期：2026 年 10 月 05 日**

**功能描述**
基于 ESP32S3-Cam 完成图像采集、HSV 红蓝双色识别、色块坐标解算，搭建 FreeRTOS 多任务框架，将识别数据存入全局数组，完成单机视觉闭环调试，为后续 ESP32 与 STM32 的 IIC 通信联调奠定基础。

**开发历程**


- 1. 初始代码试错与报错排查
初期沿用旧工程代码结构，直接调用自定义摄像头初始化函数与色块识别函数，编译持续报错，出现 undefined reference 链接错误。经排查问题根源：工程原有 camera_setting.c 仅实现注册摄像头接口，无独立初始化函数实体；同时存在旧函数残留、文件结构不匹配、C/C++ 混合编译识别异常等问题，导致编译器无法匹配函数实体。

- 2. 工程结构重构与方案优化
摒弃旧代码混乱架构，统一文件分工：ino 文件仅保留视觉识别任务，cpp 文件独立存放 IIC 从机通信逻辑，新建专用头文件统一结构体、全局变量与函数声明，解决类型未定义、变量无法共享问题。废弃失效的旧识别函数，重写完整 RGB565 转 HSV 像素解析逻辑，自主实现红蓝颜色阈值判断、色块像素统计与中心坐标计算。

- 3. 多任务架构适配调试
适配官方摄像头底层驱动，放弃手动初始化摄像头方式，使用工程原生注册接口完成图像采集。搭建双队列多任务架构：底层任务采集图像帧存入队列，视觉任务异步读取图像、完成颜色识别，将坐标数据更新至全局数组，规避内存泄漏与画面卡顿问题。删除无效注册函数，修正作用域报错，彻底解决编译报错问题。

- 4. 编译烧录与功能验证
清理 Arduino 编译缓存，完整编译工程无报错，成功烧录固件至 ESP32S3。上电测试，摄像头正常启动采集画面，可精准识别红色、蓝色色块，串口实时输出色块中心 X、Y 坐标；移除草块可正常判定无目标状态，坐标复位，单机红蓝颜色识别功能开发调试成功。

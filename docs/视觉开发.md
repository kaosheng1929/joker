硬件通信调试阶段
安装 CH340 驱动，将 ESP32-CAM 底板使用 USB 线连接电脑，电脑成功识别USB-SERIAL CH340 (COMx)串口，硬件链路通信正常，硬件基础环境调试完成。
方案初选：Arduino IDE 开发路径
初步计划使用 Arduino IDE 作为开发工具，通过 USB 线完成 ESP32-CAM 底板的程序烧录与调试。
在部署环境时，尝试安装 Espressif Systems 2.0.14 版本及其他离线版本 ESP32 开发板包，但多次校验均失败，无法完成开发板核心依赖的安装，该开发路径无法继续推进，决定放弃 Arduino IDE 方案。
方案切换：ESP 官方 Flash 工具方案
放弃 Arduino 开发环境，更换开发方案，采用乐鑫官方 Flash 工具，直接烧录预编译好的 ESP32-CAM 摄像头固件，绕开 Arduino IDE 开发板包安装失败的问题，继续推进视觉模块固件部署工作。
后续规划
固件烧录完成后，将验证摄像头图像采集功能，测试图像传输、参数配置等视觉基础能力。

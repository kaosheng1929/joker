1.## 开发环境搭建与工具链选型
 
  **日期**：2026年10月2日

 **功能描述**：搭建 ESP32-CAM 视觉模块的串口通信、固件编译与烧录调试环境，完成硬件链路适配与开发工具链定型，为后续图像采集、视觉识别功能开发奠定基础。 
 
  **开发历程**：
 - 工具选型对比：初期对比 Arduino IDE、乐鑫官方开发工具等多套方案。考虑到ESP32-CAM视觉开发适配性与零基础快速落地需求，初步选定 Arduino IDE 作为核心开发工具，用于程序编写、编译与底板烧录调试，适配视觉模块基础开发流程。
 - 环境踩坑排查：在部署开发环境过程中，多次安装 Espressif Systems 2.0.14 及离线版本ESP32开发板包，均出现校验失败、依赖缺失问题，无法完成核心开发组件安装，导致无法正常编译程序，原开发链路阻塞。
 - 方案迭代与定型：为规避开发环境兼容问题、保证项目推进稳定性，果断放弃 Arduino IDE 开发方案，切换使用乐鑫官方 Flash 烧录工具，通过预编译固件直接完成ESP32-CAM摄像头固件部署，绕开开发板包安装报错问题，成功打通硬件烧录链路。
 - 基础链路调试：安装 CH340 串口驱动，通过USB线完成ESP32-CAM底板与电脑的硬件连接，电脑成功识别 USB-SERIAL CH340 串口，硬件通信链路正常，完成视觉模块底层硬件环境搭建。

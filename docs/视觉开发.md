CRTC2026 视觉开发日志
##1. 开发环境搭建与工具链选型
**日期**：2026 年 910月 2 日
**功能描述**：搭建 ESP32-CAM 图像采集模块的通信、固件烧录开发环境，完成硬件与电脑的通信调试，实现摄像头固件部署，为后续视觉功能开发提供基础。
**开发历程**：
——**硬件通信调试**：安装 CH340 串口驱动，使用 USB 线连接 ESP32-CAM 底板与电脑，电脑成功识别USB-SERIAL CH340 (COMx)串口，硬件链路通信正常，硬件基础环境调试完成。
——**工具选型初试**：初步计划选用 Arduino IDE 作为开发工具，通过 USB 线完成 ESP32-CAM 底板的程序烧录与调试。在部署环境时，尝试安装 Espressif Systems 2.0.14 版本及其他离线版本 ESP32 开发板包，但多次校验均失败，无法完成开发板核心依赖的安装，该开发路径无法继续推进。
——**方案切换**：放弃 Arduino IDE 开发环境，更换开发方案，选用乐鑫官方 Flash 工具，直接烧录预编译好的 ESP32-CAM 摄像头固件，绕开 Arduino IDE 开发板包安装失败的问题，继续推进视觉模块固件部署工作。

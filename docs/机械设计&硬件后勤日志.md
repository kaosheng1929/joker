## 2.底盘运动

**日期**：2026年9月26日、10月1日

**功能描述**：

- 1.功能目标：实现四个轮子和马达的固定，并将开关、电池盒安置，做到零件连结紧密，不掉轮、不飞马达、不翻车，线路得当，重心适宜，为整车实现运动和装配的机械基础安排。

- 2.功能拆解：固定马达→固定轮子→焊接开关与电池盒→固定电池盒→固定开关→整理导线。

- 3.功能指标：

     外形：整齐，零件安装位置正确，螺丝拧紧；

     稳定：从<=300mm处自由落体无零件掉落或松动。

     速度：在0.3m/s——1m/s间，且能减速。

     转弯：转弯弧度所对圆心半径不大于小车体长。

     抓地：在比赛场地上不打滑。

     停车：有断电急刹车，能实现较准确停靠，误差<=150mm 。

**开发历程**：

- >1.需求：

- 实现小车快速从出发点到达目标方块处，并减速至能抓取能量方块。
  
- >2.方案：

-  1. 在底盘背面四个弯折处固定马达，需要螺丝和固定板，使马达稳固且朝向对称；

  2. 在马达转口处接上麦轮，用螺丝加固，确保马达与车轮同步运动；

  3. 准备滑动开关，将其与电池盒导线焊接，确保线路联通，开关on/off要调试，并用彩笔标注；

  4. 在底盘背面用螺母和螺丝固定好电池盒，令其靠中心（？），使整车重心居中，确保麦轮运动的准确性；

  5. 用胶水（？）固定好开关，确保其不晃动；

  6. 将导线拉至底盘正面，做到无多余的线路缠绕；

  7. 大于300MM高度摔车测试。


- >3.计算：

  -  1.测量了固定板所需孔位的大小，12.0*2.5mm。

  -  2.估算了小车所需速度0.3——0.6m/s  。
 
  -  3.加速度约为0.3——0.45m/s*s   。

- >4.结构：

- 1.固定设计：M3螺丝+螺母/环氧AB胶/502/胶带。

- 2.线路设计：导线紧贴底盘。

- >5.装配：

- 1.（问题）安装马达和麦轮时发现马达无法被现有底板和螺丝固定；
  
     （解决）在网上参考了智能小车拼装视频后，发现了固定板的存在，于是纳入清单。

  2.（问题）在固定板到后进行二次拼装，却发现固定板厚度虽然与底板孔位一致（2.5mm），但由于马达阻挡，导致能用孔位只有约1.5mm。

    （解决）按照模型图自己动手绘制草图并3D建模，调整厚度为1.5mm，安排3D打印（PLA走起）。

  3.（问题）电池盒虽然配备导线，但无开关；

    （解决）原设想自制，但并未找到适宜材料，由于时间紧迫，遂放弃，只好去网购一个标准尺寸的滑动开关；

  4.（问题）焊接开关时，发现电池盒原导线过长，可能使线路凸起不规整；

    （解决）使用水口钳修剪过长导线，在拿其它导线练手十几次后，经二次裁剪才成功“去外皮留全芯”；接着焊接内部芯丝与开关。

  5.（问题）安装电池盒时，发现盒子的孔位与底板的孔位不能全部对上，只能固定一半；

    （？解决）到时候用环氧AB胶/502解决。

  6.（问题）固定开关时，虽然孔位对上，但由于存在偏差，开关与孔位无法完美契合，存在空隙；

    （？解决）到时候用环氧AB胶应对。

- >6.调试：

- 1.初次拼装，试了马达接上轮子，发现二者外形契合且能同步运动。

  2.二次拼装，强行用标准固定板卡零件，虽然初步看上去固定结实，但在第3次70cm抗摔测试，固定板受挤压力太强而断裂，且有两个轮子与马达脱离，决定下次高度调整<300mm&>180mm。

  3.焊接开关与电池盒导线时，用万用表初步鉴定线路的畅通且无短路，开关能实现断流；之后，装上电池，与一个马达组成串联电路，确认开关开启通电马达转动导线发烫、开关关闭断电马达停止转动导线停止发烫且散热。

## 3.方块携带

**日期**：2026年9月24日、9月30日、10月1-3日

**功能描述**：

- 1.功能目标：

- 在整车上实现：到达目标物品 → 抓取 → 提升 / 搬运 → 放置，且全程不翻车、不损坏物品、不晃动。

- 2.功能拆解：

  1.空间到达：够得着任务区任意取放点→臂长、关节自由度。

  2.抓取承载：抓取物品不掉落→抓夹、摩擦面。

  3.提升搬运：拿稳物品上升→关节、舵机。

  4.姿态保持：整车不随意晃动→配重、舵机速度比例。

  5.接口协议：听从主板的命令→线路设计、接口预留。

- 3.功能指标：

  1.额定负载：抓夹为11.29g力的10倍，小车能携带15个以上的方块。

  2.工作半径：100——150mm  。

  3.定位物品：精度在2——3mm   。

  4.单次时间：小于等于3——4s   。

  5.物资保护：车上的方块无法被挤压、夹取、抖动等方式盗走。

**开发历程**：

- 1.需求：

- 从台面上抓取边长为30mm的能量方块，放置小车上的储料仓，速度控制在<=3——4s  。

- 2.方案：

  1.框架：框架式（看起来省重量）+平板分担受力；

  2.关节：采用轴承+齿轮（欣赏别人作品时，了解到“轴承”）；

  3.自由度：舵机数量为3，MG995用于肩部旋转、SG90分别用于肘和腕；

  4.抓夹：竖直/水平夹取（哪个更快呢？要不一起设计了吧）；

  5.料仓：先来个置物板凑合一下，至少放两个物块。

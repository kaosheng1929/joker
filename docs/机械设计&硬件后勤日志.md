# CRTC2026 机械设计日志


## 1.机械设计环境搭建

**日期**：2026年9月20日——9月29日

**功能描述**：

- 完成Solidworks的环境搭建和软件下载，并且完成软件常用功能的学习

**开发历程**：

- 1.SW的下载安装：

- 对比了主流的3D建模软件，在新手友好的fusion360和正宗机械师爱用的Solidworks中选择了后者，并从B站上找到“阿奇”博主，跟着其教程下载并安装SW。

- 遇见问题：SW软件安装好后打不开，弹出（-8，544，0）报错

- 解决办法：打开B站搜索关键词“SW”“无服务认证”，跟着相应视频将C盘netapi32.dll关键文件复制粘贴到D盘SW安装文件目录下之后，重启电脑、成功打开。

- 2.SW的草图学习

- 学习知识：get了草图绘制、智能尺寸的使用，初步接触了拉伸凸台。

- Q：如何快速使用草图功能？

- A：鼠标右键按住滑动了解一下。

- 3.SW的特征学习

- 学习知识：终于会了拉伸凸台的起始位置和终止位置设置，同时学了拉伸切除、旋转切除、异形台体、镜像实体等操作。

- Q：如何在曲面上作图？

- A：不要犹豫，大胆新建基准面、基准轴，理解文字、直接干!!!（>_<）

- emm(o_O),习得并实操了钣金的简单功能（如基体法兰和法兰线）及焊件的焊接，然后视频结束，学习同理；但是，关于机械臂的材质有了采用钣金的不成形想法，有待接下来考量。
